## 3. 过程中定位并修复的缺陷(全部留痕 journal)

1. **假步进毒化**:出界判负补丁字段未初始化 → 首帧 AttributeError 杀死接收线程 →
   训练在陈旧观测上 2400 假步/s 空转。修复:初始化 + `raise_on_stale` 护栏
   (训练时连接异常即抛错,静默毒化永久变有声失败)。
2. **出界不判负**:上游「|cte|>2×max_cte 忽略」宽限使冲远的车永不终止。
   修复:|cte|>max_cte 一律判负,reset 后前 5 步出生宽限。
3. **异步评测假象**:高增益救车动作在 20Hz 异步遥测下失稳,异步评测 avg 仅 75 步;
   同步 0.05s 评测 2003 步——验收协议据此修订为同步口径。
4. 工程类:默认保存路径覆盖续训源(100k 模型一度被短测试覆盖,从 checkpoint 恢复)、
   并行训练共享 best/ckpt 目录互写(--run-name 隔离)、headless 相机回读挂起
   (视觉轨改异步)、运维 pkill 误杀(端口级清理铁律)。
